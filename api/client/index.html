    Client ¶

    Client(
    path: Path | str,
    *,
    transport_factory: Callable[[], Transport]
    | None = None,
    qr_callback: Callable[[object], Awaitable[None] | None]
    | None = None,
    push_name: str = DEFAULT_PUSH_NAME,
    platform: str = "chrome",
    version: tuple[int, int, int] = DEFAULT_VERSION,
    ack_timeout: float = DEFAULT_ACK_TIMEOUT,
    auto_receipts: bool = True,
    media_transport: MediaTransport | None = None,
    node_observer: Callable[[Node], None] | None = None,
    sent_observer: Callable[[Node], None] | None = None,
    reconnect: bool = True,
    reconnect_delay: float = 1.0,
    max_reconnect_delay: float = MAX_RECONNECT_DELAY,
)

    A connected WhatsApp session.

    Usage:

    client = Client("bot.session", qr_callback=show_qr)
await client.connect()
await client.send_text("4917...@s.whatsapp.net", "hi")
await client.run()          # serves until closed

    connect async ¶

    connect() -> ClientInfo

    Log in (pairing first if the session file is new) and start serving.

    Returns as soon as the server accepts the login payload. Pairing through a QR code calls qr_callback from the connection task while this method waits.

    run async ¶

    run() -> None

    Connect and then serve until close() is called.

    close async ¶

    close() -> None

    Stop serving and release the session file.

    sync_app_state async ¶

    sync_app_state() -> list[SyncedCollection]

    Pull app state patches (contacts, mutes, pins, ...) for every collection.

    Requires sync keys, which WhatsApp shares from the phone; without them the call raises and the local copy stays as it is.
